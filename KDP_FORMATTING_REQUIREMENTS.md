# Amazon KDP Formatting Requirements

## Overview
Amazon KDP accepts multiple file formats but has specific requirements for each. This document outlines the key formatting requirements to ensure manuscripts are KDP-ready.

## eBook (Kindle) Format Requirements

### Accepted File Formats
- **DOC/DOCX** (Microsoft Word) - Most common and recommended
- **EPUB** - Convertible to MOBI by KDP
- **MOBI** - Amazon's native format
- **HTML** - For advanced users
- **TXT** - Plain text (limited formatting)

### Text Formatting
- **Layout**: Reflowable (recommended) - text adapts to screen size
- **Fixed Layout**: Only for specialized books (children's picture books, cookbooks with images)
- **Font**: Any standard font (Times New Roman, Arial, Garamond recommended)
- **Font Size**: 12pt for body text is standard
- **Line Spacing**: 1.5 or 2.0 (double spacing)
- **Paragraph Indentation**: 0.3-0.5 inches first-line indent OR blank line between paragraphs (not both)

### Images
- **Format**: JPEG or TIFF
- **Resolution**: Minimum 300 DPI
- **Color Mode**: RGB for color images, Grayscale for black and white
- **File Size**: Keep individual images under 5MB

### Structure Requirements
- **Front Matter**: Title page, copyright page, dedication (optional), table of contents
- **Main Content**: Chapters with consistent heading styles
- **Back Matter**: Author bio, other books, acknowledgments (optional)
- **Page Breaks**: Use proper page breaks (Insert > Page Break), not multiple Enter keys
- **Headers**: Use H1 for book title, H2 for chapter titles, H3 for subheadings

### What to Avoid
- ❌ Track Changes enabled
- ❌ Comments or annotations
- ❌ Manual page numbers (KDP adds these automatically)
- ❌ Headers/footers (except for print books)
- ❌ Excessive blank pages
- ❌ Hard-coded formatting (use styles instead)

## Print Book (Paperback/Hardcover) Format Requirements

### File Format
- **PDF** (preferred) - All fonts must be embedded
- **DOC/DOCX** - KDP will convert to PDF

### Trim Sizes (Most Common)
- **6" x 9"** (15.24 x 22.86 cm) - Most popular for novels and non-fiction
- **5" x 8"** (12.7 x 20.32 cm) - Compact size for fiction
- **8.5" x 11"** (21.59 x 27.94 cm) - Workbooks, textbooks

### Margins
- **Standard**: 1 inch (2.54 cm) on all sides
- **Inside Margin (Gutter)**: Add 0.125-0.25 inches extra for binding
- **Minimum Text Size**: 7-point font (anything smaller may be rejected)

### Bleed Settings
- **With Bleed**: Extend design 0.125 inches (3.2 mm) beyond trim size
- **Without Bleed**: Keep all content within trim size margins

### Page Count
- **Minimum**: 24 pages (including front and back matter)
- **Maximum**: 828 pages for black & white, 800 for color

### Images for Print
- **Resolution**: 300 DPI minimum (higher is better)
- **Format**: Embedded in PDF
- **Color Mode**: CMYK for color printing, Grayscale for black & white

## Cover Requirements

### eBook Cover
- **Format**: JPEG or TIFF
- **Dimensions**: Minimum 1000px on shortest side, ideal 2560 x 1600 pixels
- **Aspect Ratio**: 1:1.6 (height to width)
- **File Size**: Maximum 50MB
- **Color Mode**: RGB

### Print Book Cover
- **Format**: PDF (all fonts embedded)
- **Type**: Full wrap cover (front, spine, back)
- **Calculator**: Use KDP's Cover Calculator for exact dimensions based on page count
- **Bleed**: 0.125 inches on all sides
- **Spine Width**: Calculated based on page count and paper type

## Metadata Requirements

### Title
- **Maximum Length**: 200 characters (including spaces)
- **Subtitle**: Optional, up to 200 characters
- **Series**: Optional series name and number

### Description
- **Length**: 2,000-4,000 characters recommended (maximum 4,000)
- **HTML Formatting Allowed**: `<b>`, `<i>`, `<br/>`, `<ul>`, `<li>`
- **First 3 Lines Critical**: Visible before "Read more" button

### Keywords
- **Count**: 7 keywords/phrases
- **Length**: Each keyword up to 50 characters
- **Focus**: Buyer-intent keywords, not single words

### Categories
- **Count**: Up to 2 categories during upload (can request up to 10 via support)
- **Browse Categories**: Choose specific subcategories, not broad categories

## ISBN Requirements

### eBook
- **Optional**: Amazon provides free ASIN (Amazon Standard Identification Number)
- **If Using ISBN**: Must be for eBook format specifically

### Print Book
- **Required**: ISBN-13 format
- **Options**:
  - Free Amazon ISBN (Amazon listed as publisher, Amazon-only)
  - Your own ISBN from Bowker ($125) or country's ISBN agency

## Common Formatting Errors to Avoid

1. **Inconsistent Formatting**: Different fonts, sizes, or spacing throughout
2. **Missing Page Breaks**: Using Enter key instead of Insert > Page Break
3. **Embedded Fonts Not Included**: PDF fonts not embedded (print books)
4. **Low-Resolution Images**: Below 300 DPI
5. **Text Outside Margins**: Content too close to edge (print books)
6. **Track Changes Enabled**: Must accept all changes before export
7. **Hyperlinks in Print**: Remove or convert to footnotes for print books
8. **Incorrect Trim Size**: PDF doesn't match selected trim size

## Pre-Upload Checklist

### For All Formats
- [ ] Spell check and grammar check completed
- [ ] All track changes accepted
- [ ] All comments removed
- [ ] Table of contents links work (eBook)
- [ ] Copyright page included
- [ ] Consistent formatting throughout

### For eBooks
- [ ] File format is DOC/DOCX or EPUB
- [ ] Images are 300 DPI, RGB color mode
- [ ] No headers/footers
- [ ] Reflowable layout (unless fixed layout required)
- [ ] Tested in Kindle Previewer

### For Print Books
- [ ] PDF with embedded fonts
- [ ] Correct trim size set
- [ ] Margins meet minimum requirements (including gutter)
- [ ] Images are 300+ DPI
- [ ] Bleed settings correct (if applicable)
- [ ] Page count between 24-828 pages
- [ ] Ordered proof copy for review (recommended)

## Tools and Resources

### Amazon's Free Tools
- **Kindle Create**: Format eBooks with guided interface
- **Kindle Previewer**: Preview how eBook looks on different devices
- **Cover Calculator**: Calculate exact print cover dimensions
- **KDP Templates**: Download pre-formatted Word templates for print books

### Recommended Third-Party Tools
- **Microsoft Word**: Most common for manuscript creation
- **Google Docs**: Free alternative, export to DOCX
- **Vellum**: Professional formatting software (Mac only, paid)
- **Atticus**: All-in-one formatting tool (paid)
- **Reedsy Book Editor**: Free online formatting tool

## Next Steps After Formatting

1. **Preview Your Book**: Use Kindle Previewer (eBook) or order proof copy (print)
2. **Upload to KDP**: Go to kdp.amazon.com and create new title
3. **Enter Metadata**: Copy-paste optimized title, description, keywords
4. **Set Pricing**: Choose royalty tier (70% for $2.99-$9.99)
5. **Publish**: Review and click publish (24-72 hours for review)

**Note**: Amazon KDP requirements may change. Always check the official KDP Help Center for the most current guidelines.
