# Amazon KDP Publishing Requirements - Research Summary

**Source:** AuthorImprints.com "Self-Publish Quickly on Amazon—Includes 20-Step Checklist"
**Date:** January 5, 2026

## Key Requirements for Amazon KDP Publishing

### Essential Files Needed:
1. **Book cover** - Formatted to Amazon KDP specifications
2. **Interior manuscript** - Typeset to Amazon KDP specifications  
3. **ISBN** - For print edition (decision is permanent - cannot change after publishing without losing reviews)
4. **KDP account** - Established in author or publisher name
5. **Metadata** - Complete information for book listing

### Five Assumptions for Quick Publishing:

1. **Be Decisive** - Publishing requires many decisions (cover design, pricing, etc.). Indecision slows the process.

2. **Legal Reviews Complete** - Books with trademarks, excerpts, music lyrics, unlicensed images, or claims should be reviewed by attorney. Previously published books need proof of rights reversion.

3. **Editing Complete** - Text should require few/no changes after typesetting. Changes during layout are costly in time and money. Recommend: trusted readers → copyeditor → proofer.

4. **Publishing Paperback AND eBook** - Print takes longer than eBook. Best quality achieved by producing formats in succession, not concurrently. eBook-only can go much faster.

5. **Book Available for Public Purchase** - If book is only for family/friends/business (not public sale), cannot use KDP for printed proof copies.

### Critical Metadata Elements (Cannot Change After Publishing):
- ISBN
- 8 other metadata elements (specific list in full checklist)
- Changing these requires republishing and forfeits customer reviews

### Format Options:
- **eBook only** - Fastest path to publishing
- **Paperback** - Takes more time to produce
- **Audiobook** - Takes weeks/months, requires complete book before starting (narration, editing, mastering). Amazon ACX takes 14+ days for processing.

## Complete 20-Item Amazon KDP Publishing Checklist

### Account Setup (2 items):
1. **KDP account** - Established
2. **MyIdentifiers.com** - If in US and buying ISBNs

### Files Required (4 items):
3. **Paperback book cover** - PDF format
4. **Interior file for paperback** - Word or PDF
5. **eBook cover file**
6. **eBook ePub file** - Several formats supported, ePub is safest

### Metadata - Information About the Book (14 items):

**Cannot Be Changed After Publishing (marked with *):**
7. **Title*** - Permanent
8. **Subtitle*** - Permanent
9. **ISBN*** - Permanent (if not using free ISBN)
10. **Publisher name*** - Permanent (if bought ISBNs; free ISBN means Amazon is publisher and book cannot be printed elsewhere)
11. **Author name*** - Permanent
12. **Language*** - Permanent
13. **Edition number*** - Permanent
14. **Print book dimensions*** - Permanent
15. **Type of paper for paperback*** - Permanent

**Can Be Changed Later:**
16. **Contributors** - Illustrator, foreword writer (not editor unless anthology)
17. **Selling prices**
18. **Categories** - Two required (minimum 1, maximum 10 later)
19. **Keywords**
20. **Book description**

### Critical Warning:
> **9 metadata elements marked with * cannot be changed after publishing your print book unless you republish using a different ISBN. If you republish, customer reviews usually stay with the old version.**

## Publishing Timelines

### Kindle eBook:
- **Amazon states:** Less than 72 hours
- **Actual experience:** Average less than 24 hours

### Print Books:
- **Author proof:** Less than few hours processing + shipping (proof available in less than a week)
- **Amazon states:** Live in store in 3-5 days
- **Actual experience:** About 2 days for availability, full listing complete in 3 days

## Tasks That Take Extra Time (Avoid if Rushed):
- Index (book must be complete first)
- Library of Congress Control Number
- Pre-publication reviews with advance reader copies
- Pre-order setup
- Print runs (use print-on-demand instead)
- Hardcovers with dust jackets

## Amazon File Checks:
Amazon's automated process checks for:
1. Text on cover being cut off when printed
2. Anything blocking/overlapping barcode
3. Content freely available on other websites
4. Rights to publish the book

## Costs:
- **KDP:** Free to use
- **ISBNs:** Additional charge (Amazon's free ISBN cannot be used with other printers)
- **IngramSpark alternative:** $49 setup + $25 revision fee
